Secure tokens

Scoped API keys you can rotate any time.

Getting an API key

Generate a scoped API key from Settings, then send it as a Bearer token on every request. Keys can be limited to specific data and rotated at any time.

Base URL

All endpoints are served over HTTPS at https://api.nncdigital.co.in/v1. Requests and responses use JSON.
